# 맵 계획 — Inflation RPG · Resolute Hero 와 거의 같은 이동 · 진행으로

> 목표: 두 게임처럼 **필드를 걸어 다니다가 싸우고, 정해진 자리의 보스를 꺾고 다음 지도로 가는** 구조.
> 지금 `tools/map-draft.html` 은 「칸마다 적이 서 있는」 초안이었는데, 두 게임을 조사해 보니
> 그 방식(걸어서 적을 골라 잡기)은 두 게임과 다릅니다 — 아래에서 바로잡습니다.

## 1. 두 게임에서 확인한 것

### Inflation RPG (2013, 사사키 타츠키 · 안드로이드/iOS)

- **이동**: 필드를 걸어 다닙니다. 걷는 동안 **조우 게이지(6칸)** 가 찹니다. 많이 찰수록 몬스터를 만날 확률이 높습니다 (3칸이면 대개 만남). 칸에 적이 서 있지 않고 **걷기 = 랜덤 조우의 게이지** 입니다.
- **게이지 조절 장비**: 조우 감소 반지(느리게 참) · 이동 속도 보석 · 즉시 조우 반지(단추로 바로 싸움).
- **진행**: 지도마다 권장 레벨이 적혀 있지만 장비가 좋아지면 의미가 없어집니다 — **장비가 어디서 사냥할지를 정합니다.**
- **BP(전투 점수) = 이 게임의 에너지**: 30 으로 시작, 싸울 때마다 1, **지면 3**. 0 이면 회차 끝. **보스를 꺾으면 BP 를 조금 돌려받습니다.**
- **보스**: 지도 위 정해진 자리에 서 있고 **한 회차에 한 번만** 아이템을 줍니다. 센 보스는 일단 건너뛰고 나중에 와도 됩니다. **숨은 보스**도 있습니다.
- **조건부 구역**: 「장비를 N종 이상 모아야 들어갈 수 있는」 구역이 있습니다. 조건이 모자라면 1 HP 짜리 껍데기만 나옵니다.
- **보너스 칸**: 필드 곳곳에 무작위로 생겨 경험치 · 골드 · 적 약화 같은 보너스를 줍니다.
- **미로 지도**: 네 시작점 중 무작위로 시작해 중앙의 보스까지 가는 식의 지도도 있습니다.
- **하드 모드**: 레벨 10만을 넘기면 열림. 적 체력 ×9.9 · 공격 ×8.8, 경험치 ×10 · 골드 ×5, 지도의 권장 레벨이 「?????」 로 가려지고 조우가 줄어듭니다.
- **회차**: BP 가 0 이 되면 끝. 장비와 구입한 칸은 남고, 골드는 사라집니다.

### Resolute Hero RPG (Geometric Applications, 2021)

- **이동**: **월드맵 위를 걸어 다닙니다.** 가상 조이스틱 조작 모드가 있고(v0.8.1), 장비 능력에 **이동 속도**(월드맵에서 움직이는 빠르기)가 있습니다.
- **지도**: 레벨대가 정해진 구역이 스무 개 남짓 (Overworld Lv.1~1,500 → … → Order). 입구가 숨은 구역(Secret Tunnel 등)도 있습니다. 후기: 「처음엔 지도가 헷갈리지만 회차 중심으로 설계돼 있고, 조금만 탐험하면 뒷부분으로 안내된다」.
- **에너지**: 싸울 때마다 1. 경험치/골드 집중 능력은 싸울 때 에너지를 더 씁니다. **보스는 에너지 상한이 있고** (한 보스에서 얻는 에너지는 2 까지), 보스에게서 에너지를 영구히 빼앗는 무기가 있습니다 (우리의 「격을 삼키는 검」).
- **전투 전 정보**: 승률 · 적별 남은 드롭 · **언더레벨 경험치** · 적이 가끔 두르는 보너스 — 이미 우리 게임에 들어 있습니다.

### 확인하지 못한 것 (솔직하게)

- Resolute Hero 에서 **적이 지도 위에 보이는지, 부딪히면 싸우는지, 걸으면 게이지로 만나는지**는 공개된 글에서 못 찾았습니다.
- 두 게임의 **구역을 잇는 방식**(문 · 포털 · 이어진 월드)도 글로는 확인하지 못했습니다.
→ 직접 해 보신 느낌이 가장 정확합니다. 아래 계획은 「확인된 것은 그대로, 못 찾은 것은 Inflation RPG 방식으로」 잡았고, **다르게 기억하시면 말씀해 주세요.**

## 2. 우리 게임에 옮기는 방식

| 요소 | 두 게임 | 우리 게임에서 |
|---|---|---|
| 이동 | 필드를 걷는다 (조이스틱 / 방향 단추) | 같음 — 방향 단추 · 조이스틱 · 방향키/WASD |
| 일반 적과 만나기 | **걸으면 조우 게이지가 차서 랜덤 조우** (Inflation) | 같음 — 그 구역의 일반 적 풀에서 무작위. **칸에 서 있는 적은 없음** (골라 잡기 불가 → 지금의 밸런스 유지) |
| 에너지 | 싸울 때마다 1, 지면 더 잃음, 보스가 일부 돌려줌 | **이미 같음** (일반 −1 · 패배 −2/−3/−5 · 보스 환급 · 삼키는 검) |
| 보스 · 정예 · 히든 | 지도 위 정해진 자리에 서 있음, 한 회차 한 번 | **이미 같은 규칙** — 지도 위 **눈에 보이는 표지**로 놓고 걸어가면 마주침 (물러설 수 없음) |
| 다음 지도 | 보스를 꺾고 이동 | 보스를 꺾으면 **출구(포털)** 가 열림 |
| 숨은 구역 | 조건부 구역 · 숨은 보스 | 관측자 · 상인 · 7격 이상의 숨은 것 — 「도감 N종 이상」 같은 조건과 지도 구석의 표지로 |
| 지역 안 구분 | 지도마다 권장 레벨 | 지금의 「승률 예감 문장」이 그 역할 (권장 레벨 숫자는 안 보임) |
| 능력치 | 이동 속도 · 조우 조절 장비 | **새 특수 능력치** 후보: 이동 속도 · 조우율 (아래 결정 4) |
| 회차 후 | 하드 모드 · 레벨→경험 환산 | 「회차 반응」 아이디어(보류 중)와 묶어서 나중에 |

**지난 초안과 달라지는 점**: 일반 적을 칸에 세우던 것을 없애고 **조우 게이지**로 바꿉니다. 정예·보스·히든은 칸 위의 표지로 그대로 둡니다. (게이지 방식이 두 게임과 같고, 「골라 잡기」 문제도 사라집니다.)

## 3. 단계

**1단계 — 움직임과 조우 게이지 (글자 격자 위에서)**
- `tools/map-draft.html` 에서 일반 적 칸을 없애고 조우 게이지를 넣음: 한 칸 걸을 때마다 게이지가 차고(지역마다 비율), 차면 일반 적과 마주침 → 싸움 → 게이지 0.
- 걷기 · 벽 · 방향 입력 · 게이지가 재미있는지 먼저 확인 (그림 없이).
- 에너지는 싸울 때만, 지면 직전 칸으로.

**2단계 — 지도**
- 15개 지역 지도의 모양: 지금의 자동 생성으로 갈지, 손으로 짤지 (결정 3).
- 보스 · 정예 · 히든 표지 놓기, 출구, 숨은 구역의 입구.

**3단계 — 게임 안으로**
- `renderJourney` 의 갈림길(`crossroads`)을 맵으로 교체, 폰 배치(조이스틱/방향 단추를 엄지 자리에), 조우 게이지 표시, 싸움 중 화면 숨김 규칙과의 맞춤.
- 저장: 지금 위치를 회차 저장(`runKey`)에 넣음 (옛 저장본은 시작 칸에서 이어짐).

**4단계 — 진행 요소**
- 조건부 구역 · 보너스 칸 · (보류 중인) 하드 모드/회차 반응.

**5단계 — 그림**: 화풍을 정한 뒤 칸 · 벽 · 표지에 그림을 입힙니다 (`design/images/` 의 목록 참고).

## 4. 정해 주셔야 할 것

1. **조우 방식**: Inflation 식 게이지(걷다 보면 만남)로 가는 게 맞나요? (못 확인한 Resolute Hero 쪽이 다르다면 알려 주세요)
2. **움직임**: 칸 단위(한 칸씩) vs 부드럽게 걷기(조이스틱). 칸 단위가 폰에서 더 간단하고, 부드럽게 걷기는 두 게임에 더 가깝습니다. **추천: 칸 단위로 시작 → 나중에 부드럽게.**
3. **지도 모양**: 자동 생성 / 손으로 짠 15장. (손으로 짜려면 **Tiled** 가 좋습니다 — 아래 도구 제안)
4. **이동 속도 · 조우율 능력치**를 새로 넣을지 (장비 선택지가 늘지만 능력치 개수도 늘어납니다).
5. **한 지도 크기와 걷는 시간**: 한 회차의 템포 — 지금처럼 싸움 위주로 갈지, 걷는 시간이 더 길어도 되는지.

## 5. 도구 제안

- **Tiled** (무료 지도 편집기): 3번에서 「손으로 짠다」를 고를 때만. JSON 으로 내보내면 제가 그대로 읽어 게임 지도로 씁니다.
- **Node 내장 테스트 러너** (`node --test`): 조우 게이지 · 이동 규칙은 숫자 규칙이라 화면 없이 자동 시험을 붙이기 좋습니다. 이미 설치하셨으니 추가 설치 없이 제가 붙일 수 있습니다. (1단계 끝날 때 제안드리겠습니다)
- 그 밖에는 새 도구가 필요하지 않습니다.
