# 맵 초안 (디자인 없음)

> ⚠ **이 초안은 `docs/MAP-REFERENCE-PLAN.md` 로 대체됩니다** — 칸마다 적을 세우던 방식 대신, 구역에 들어서면 일반 몬스터 3~4마리가 스폰되어 움직이고(선공 · 후공 · 중립), 정예 · 보스는 자리를 지키는 월드맵 방식입니다.

> 지금의 「길을 떠난다」 버튼 대신 **칸을 걸어 다니며 만나는** 구조의 초안입니다.
> 그림은 전혀 없고 글자 격자뿐입니다 — 구조가 재미있는지만 보려는 것입니다.
> (이 초안의 글자 격자 페이지는 없어졌습니다 — `tools/map-draft.html` 은 이제 새 계획의 규칙으로 걷는 시험 페이지입니다.)
> 코드로 옮길 때의 이음매는 `docs/MAP-PLAN.md` 에 이미 적혀 있습니다.

## 초안의 규칙 (지금 정해 둔 값)

| 항목 | 초안 | 이유 |
|---|---|---|
| 맵 한 장 | **격 하나 = 맵 하나**, 9×7 칸, 지역마다 늘 같은 맵 | 열다섯 개를 손으로 안 짜도 되고, 같은 지역을 다시 올 때 길이 익숙해집니다 |
| 시작과 출구 | 왼쪽 가운데에서 시작, 오른쪽 가운데가 출구 | 한눈에 방향이 보입니다 |
| 출구 | **보스를 꺾어야 열림.** 보스는 출구 바로 앞 칸에 섭니다 | 지금의 「보스를 꺾으면 길이 열린다」 그대로 |
| 정예 · 히든 | 시작에서 멀리, 서로 멀찍이 퍼지게 놓음. 히든은 나타나기 전엔 빈 칸 | 안 잡아도 되지만 찾아가야 합니다 |
| 일반 화신 | 남은 칸의 약 22%에 서 있음. **잡아도 그 칸에 남아** 다시 밟으면 또 싸움 | 지금의 「한 지역에서 20~30번 싸운다」 밸런스를 지킵니다 |
| 에너지 | **마주칠 때만 1.** 빈 칸 걷기 · 벽에 부딪히기는 공짜 | 「에너지 = 싸움 횟수」 유지 (MAP-PLAN 의 권장) |
| 물러서기 | 일반은 직전 칸으로 물러남. 정해진 자리는 물러설 수 없음 | 지금과 같음 |
| 패배 | 직전 칸으로 밀려남 (에너지 손실은 지금 규칙 그대로) | |
| 벽 | 칸의 약 20%, 갈 수 없는 구석은 막아 버림. 시작 → 출구 길은 늘 이어짐 | |

바뀌지 않는 것: 전투(`beginEncounter → engage / retreat`), 승률 예감, 전리품, 강화, 화신, 골드, 상인 — **걷는 방식만 바뀝니다.**

## 정하셔야 할 것

각각 초안의 값을 먼저 적었습니다. 바꾸고 싶은 것만 말씀해 주세요.

1. **일반 화신이 칸에 남는가** — 초안: 남는다(다시 밟으면 또 싸움).
   - 사라지게 하면 맵을 훑는 퍼즐이 되지만, 한 지역 20~30번 싸움 밸런스가 깨져 칸 수나 리스폰을 손봐야 합니다.
2. **걸어서 마주치는 일반 화신을 고를 수 있어도 되는가** — 초안: 칸에 서 있는 놈이 정해져 있어 **피해 가거나 골라 잡을 수 있음.**
   - 이게 지금과 가장 큰 차이입니다. 약한 놈만 골라 잡기 · 센 놈 피하기가 가능해집니다. 정말 그래도 되는지가 핵심 결정입니다.
3. **맵 크기** — 초안: 전 지역 9×7. 격이 높을수록 커지게 할지(예: 7×5 → 13×9), 지역마다 손으로 짠 맵으로 갈지.
4. **히든(관측자 · 상인 · 숨은 것)** 의 위치 — 초안: 상인은 아직 맵에 안 넣었습니다. 맵 어디에 서 있을지(눈에 띄게/구석에)를 정해야 합니다.
5. **화신이 데려다 준다** (1격 → 7격 바로) — 초안은 이 기능을 안 다룹니다. 맵에서는 「출구 앞에 화신 문」 같은 칸으로 둘 수 있습니다.
6. **조작** — 폰에서는 방향 단추 네 개가 아래에 필요합니다. 「길을 떠난다」 같은 큰 단추 자리를 어떻게 쓸지.

## 초안 도구로 확인할 것

- 맵이 지루하지 않은가 (벽 20% · 일반 22%가 적당한가)
- 보스까지 가는 길에서 정예를 만날지 말지가 **선택**으로 느껴지는가
- 걷는 칸 수 대비 싸움 수가 지금의 「길을 떠난다」 리듬(싸움 위주)과 비슷한가
- 15개 지역 모두 보스가 출구 앞에 놓이고 길이 이어지는지 — 시험으로 확인했습니다 (전 지역 통과)

3. 폰 배치(방향 단추) · 상인/관측자 자리.
4. 디자인은 맨 마지막 — 화풍을 정한 뒤 칸 · 벽 · 길에 그림을 입힙니다.
