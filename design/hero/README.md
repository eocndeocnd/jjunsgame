# 주인공 픽셀 — 시안 (게임에는 아직 안 들어감)

`node design/hero/hero.js` 로 다시 뽑습니다. 그림은 `hero.js` 안의 글자 그림이 전부입니다 (글자 하나 = 픽셀 하나).

| 파일 | 내용 |
|---|---|
| `hero.png` | 96×16, 바탕 투명 — 한 칸 16×16 (지도 한 칸과 같은 크기). 앞 서 있기 · 앞 걷기 · 뒤 서 있기 · 뒤 걷기 · 옆 서 있기 · 옆 걷기 |
| `hero-preview.png` | 8배 — 위는 어두운 돌바닥, 아래는 풀밭 위 |

- 옆모습은 오른쪽을 봅니다. 왼쪽은 좌우로 뒤집어 씁니다.
- 걷기는 두 칸(서 있기 · 걷기)을 번갈아 — 옆모습 걷기는 앞발과 손이 앞으로 나갑니다.
- 차림: 낡은 작업 점퍼(반사띠) · 목장갑 · 작업 바지 · 작업화 · 가슴의 작은 명찰. 색은 11가지.
