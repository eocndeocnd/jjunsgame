# 주인공 픽셀 — 시안 (게임에는 아직 안 들어감)

`node design/hero/hero.js` 로 다시 뽑습니다. 사용자가 그려 온 캐릭터 그림을 바탕으로 픽셀 격자에 맞춰 새로 찍었습니다.

- **부품을 한 번만 찍고 맞춰 끼웁니다** — 머리(앞 · 뒤 · 옆) · 몸통 · 팔 · 다리 · 가방을 글자 그림으로 한 번씩만 그리고,
  동작마다 부품 자리만 옮깁니다. 그래서 모든 칸이 같은 격자에 맞고, 색이나 부품 하나를 고치면 모든 칸이 같이 바뀝니다.
- 테두리는 부품마다 둘레에 닿은 색을 짙게 두릅니다 — 겹치는 곳(팔과 몸통, 턱과 옷깃 …)은 안쪽 선이 됩니다.

| 파일 | 내용 |
|---|---|
| `hero.png` | 게임용 한 장 — 한 칸 32×36, 바탕 투명. 줄: 동작 × 방향(앞 · 뒤 · 왼쪽 · 오른쪽), 칸: 프레임 (모자란 칸은 비움) |
| `hero-preview.png` | 모든 칸 3배 — 줄: 동작, 묶음: 앞 · 뒤 · 왼쪽 · 오른쪽 |
| `hero-anim.png` | 움직이는 PNG 3배 — 줄: 동작, 칸: 방향 |
| `hero-onmap.png` | 맵 시안(한 칸 16px)의 숲 위에 4배 — 지도와의 크기 비율 |

| 동작 | 프레임 | 몸짓 |
|---|---|---|
| 정지 | 4 | 숨쉬기 · 눈 깜빡 |
| 대기 | 2 | 두리번 (옆은 한숨) |
| 걷기 | 4 | 한 발 · 지나감 · 다른 발 · 지나감 |
| 달리기 | 4 | 크게 · 앞으로 기울여 |
| 공격 | 4 | 당기고 · 앞으로 뻗고 · 버티고 · 돌아옴 |
| 피격 | 3 | 번쩍 · 뒤로 밀림 · 돌아옴 |
| 대화 | 4 | 손짓하며 입을 열고 닫음 |
| 사망 | 4 | 비틀 · 무릎 · 주저앉음 · 누움 |

- 발끝은 칸 아래에서 셋째 줄(y 33). 왼쪽은 오른쪽을 좌우로 뒤집은 것.
- 차림: 곱슬한 갈색 머리 · 지퍼를 연 검은 후드 집업과 흰 티 · 검은 백팩(갈색 패치 · 고양이 키링) · 짙은 바지 · 흰 운동화.
