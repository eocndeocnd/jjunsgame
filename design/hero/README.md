# 주인공 픽셀 — 시안 (게임에는 아직 안 들어감)

`node design/hero/hero.js` 로 다시 뽑습니다. 그림은 `hero.js` 안의 글자 그림이 전부입니다 (글자 하나 = 픽셀 하나, 속만 칠하고 테두리는 코드가 둘레에 두름).

| 파일 | 내용 |
|---|---|
| `hero.png` | 72×96, 바탕 투명 — 한 칸 24×32 (몸은 약 18×26). 줄: 앞 · 뒤 · 옆 / 칸: 서 있기 · 걷기 A · 걷기 B |
| `hero-preview.png` | 6배 확대 |
| `hero-onmap.png` | 맵 시안(한 칸 16px)의 숲 위에 그대로 올려 4배 — 지도와의 크기 비율 |

- 비율은 레퍼런스(필드 캐릭터)처럼 큰 머리 — 머리와 몸이 거의 반반, 한 칸 반쯤의 키. 지도 한 칸(16px)보다 위로 솟습니다.
- 옆모습은 오른쪽을 봅니다. 왼쪽은 좌우로 뒤집어 씁니다.
- 걷기는 서 있기 → A → 서 있기 → B. 앞 · 뒤는 한 발씩 들고, 옆은 보폭과 손이 앞뒤로.
- 차림: 헝클어진 갈색 머리 · 낡은 작업 점퍼(반사띠) · 턱 밑으로 내린 방진 마스크 · 목장갑 · 작업 바지 · 작업화 · 가슴의 명찰.
- 테두리는 검정 하나가 아니라 닿은 색을 짙게 (머리는 짙은 갈색, 옷은 짙은 남색).
