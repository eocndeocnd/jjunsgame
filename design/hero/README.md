# 주인공 픽셀 — 시안 (게임에는 아직 안 들어감)

사용자가 AI 로 그린 캐릭터를 바탕으로 합니다. AI 그림은 픽셀이 어긋나 있어서, 그림의 픽셀 한 칸(약 7.25px)마다
가장 흔한 색을 뽑아 원래 격자(약 22×34)로 되살리고, 재료별로 나눈 뒤 어긋난 곳만 다듬었습니다.

`node design/hero/hero.js` 로 다시 뽑습니다 (`--print` 를 붙이면 다듬은 글자 그림을 출력).

| 파일 | 내용 |
|---|---|
| `hero.png` | 네 방향 한 장 — 한 칸 32×40, 바탕 투명. 앞 · 뒤 · 왼쪽 · 오른쪽 |
| `hero-preview.png` | 8배 확대 |

- 색은 AI 그림에서 재료마다 평균 낸 것 — 머리 4단 · 살 3단 · 흰색 · 회색 · 갈색 눈동자 · 후드 3단 · 가방끈 장식.
- 다듬기: 안쪽 구멍 메우기 · 끊긴 바깥 테두리 잇기 · 목 아래의 머리색을 후드색으로 · 앞얼굴(눈 · 입 · 턱)은 손으로.
- 다음: 동작 (정지 · 대기 · 걷기 · 달리기 · 공격 · 피격 · 대화 · 사망 — AI 동작표의 절반 프레임).
