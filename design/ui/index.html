UI 시안 — 지도가 화면 가득

셋 다 진짜 지도 위를 걸을 수 있고, 몬스터에 닿으면 게임 규칙 그대로 싸웁니다(전투 연출만 없음). 아무것도 저장하지 않으니 마음껏 눌러 보세요.

A · 떠 있는 칩
  • 위에 작은 칩 둘 — 지역 · 레벨 · 경험치 / 에너지 · 골드
  • 왼쪽 아래 조이스틱, 오른쪽 아래 둥근 단추 셋(가방 · 나 · 기록)과 세트 1 2 3
  • 메뉴 · 조우 · 결과는 아래에서 반쯤 올라오는 서랍 — 지도가 계속 보임
 B · RPG 창
  • 왼쪽 위 얼굴 창(레벨 · 에너지 · 경험치), 오른쪽 위 작은 지도 — 어디로 갈지 보임
  • 아래 글 창에 방금 일어난 일. 닿으면 글 창에서 「▶ 맞선다 / 물러선다」를 고름
  • ☰ 메뉴는 화면 전체를 덮는 옛 RPG 메뉴(능력치 · 차림 · 기록)
 C · 몰입
  • 지도 위에 거의 아무것도 없음 — 화면 어디든 누르면 그 자리에 조이스틱
  • 에너지는 왼쪽 위의 큰 숫자, 경험치는 아래 가장자리의 줄, 지역 이름은 들어설 때만 잠깐
  • 메뉴는 아래 손잡이를 끌어올리는 서랍, 조우는 위에 상대 · 아래에 엄지 단추 둘

고르면 그 틀로 게임 화면을 다시 짭니다. 섞어도 됩니다 (예: C 의 떠 있는 조이스틱 + B 의 작은 지도). · 게임으로
